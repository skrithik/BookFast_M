# BookFast

BookFast is a high-concurrency ticket booking platform built as a learning and portfolio project.

## Planned Technology Stack

### Frontend
- React
- JavaScript

### Backend
- Java 21
- Spring Boot
- REST APIs
- Microservices

### Database
- PostgreSQL
- Redis

### DevOps
- Docker
- Kubernetes
- Jenkins
- AWS

### Messaging
- Apache Kafka
